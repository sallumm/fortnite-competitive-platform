## Limites e evidências

Catálogo completo: hosted-catalog.json, owners: function-owners.json, avisos: advisors.json, análise por função: function-matrix-review.json. Os definers pertencem a postgres, com BYPASSRLS: por isso RLS não substitui os guardas internos. Todos os 112 definers têm search_path vazio. Cinco helpers privados permanecem executáveis conforme contrato; USAGE do schema private não concede CRUD. Os 26 avisos RLS sem policy correspondem a negação por padrão, não ausência de RLS.

Não foram chamadas RPCs mutadoras, nem inseridos JWT claims para executar casos de escrita. Testes entre contas reais/sintéticas e serviço Auth permanecem futuros. Auth/SMTP/CAPTCHA e schemas publicados pelo Data API não estão disponíveis para inspeção pelo conector atual.
