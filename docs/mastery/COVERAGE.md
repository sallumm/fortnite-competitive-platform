## Inventário de profundidade

Cada aula contém explicação original, atividade observável, critérios de avaliação, contexto temporal e fontes com alcance explícito. Cerca de 4.890 palavras no conjunto; quantidade não comprova validade. O esquema permite novas aulas sem componentes individuais. Não há páginas vazias para completar uma matriz artificial.
